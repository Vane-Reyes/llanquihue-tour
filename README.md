# LlanquihueTourApp

Sistema para cargar y filtrar tours de Llanquihue Tour desde un archivo de texto.

## Estructura del proyecto
- `src/model`: clase Tour (datos de cada tour).
- `src/data`: clase GestorDatos (lee el archivo y crea los objetos).
- `src/ui`: clase Main (ejecuta el programa).
- `resources/tours.txt`: datos de origen.

## Cómo ejecutar
Abrir el proyecto en IntelliJ IDEA y ejecutar la clase `Main` ubicada en `src/ui`.
